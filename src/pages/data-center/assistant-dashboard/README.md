# 助理对话看板

- 访问路径：`/#/data-center/assistant-dashboard`
- 菜单位置：数据中心 / 数据分析 / 助理对话看板

## 页面目标

集中查看私人用户助理的核心用户运营指标与活跃时段分布，并按助理、自然周和渠道缩小数据范围。

## 功能范围

- 页面顶部按助理单选当前数据作用域。
- 在看板内直接选择自然周，按渠道全选、单选或多选后查询。
- 展示 DAU、新增用户、人均会话数、平均会话轮次、人均消息数和角色绑定率。
- 以按日趋势图展示 DAU、新增用户和人均会话数，以 24 小时 × 7 天热力图展示会话发起时段分布。

## 交互与业务规则

- 助理选择项提供 `game_id`；渠道列表由独立接口按 `game_id` 获取。切换助理后重新加载整页数据，并将渠道重置为该助理下的全部渠道。
- 页面 Mock 数据同时依赖顶部当前业务的 `game_id`。切换顶部业务后立即按新的业务 `game_id` 更新全部指标与图表，不改变当前预览场景；加载状态仅由页面预览场景控制。
- 自然周范围为周一00:00:00至周日23:59:59。页面不提供日/周粒度切换按钮，核心指标趋势固定按日展示。
- 周选择器输入框显示所选周的周序号，右侧注释文字给出该自然周的起止日期。周序号与归属年由选择器按 ISO 规则给出，跨年周归属周四所在的年份。
- 周选择器最晚只能选到上一个已完整结束的自然周。尚未结束的本周及以后的周整行禁用、不可点击，避免查出残缺周的统计结果。
- 查询操作将当前自然周和渠道条件应用到全部指标；重置恢复默认自然周和当前助理的全部渠道。
- 多渠道场景中的用户级指标按统一用户键去重。新增用户仅统计首次使用记录落在当前选定渠道范围内的用户。
- 平均会话轮次按用户提问次数除以去重会话数计算；角色绑定率的分子与分母均按当前游戏、自然周和渠道范围内的用户去重。
- 活跃时段以会话发起时间为准，按小时统计会话数。观察期不足、接口无数据或计算分母为 0 时显示 `--`，不展示错误数值。

## 数据与接口约束

- 助理选择结果需提供稳定的 `game_id`，渠道接口返回 `channel_id` 与渠道名称；页面查询需同时携带顶部业务 `game_id`、当前助理 `game_id`、自然周起止时间和选中的渠道 ID 列表。
- 原型通过确定的 Mock 响应模拟按 `game_id` 获取渠道列表及筛选后的指标变化，不连接真实数据服务。

## 页面预览场景

- 正常有数据：默认助理、自然周和全部渠道下展示完整指标与图表。
- 看板加载中：首次进入页面时指标与图表尚未返回数据，保留筛选区和看板结构，仅显示加载反馈，不展示业务数据或空态。
- 当前范围无数据：指标显示 `--`，趋势和活跃时段区域分别展示与业务含义一致的空态。
- 看板加载失败：保留当前助理与筛选条件，提供重新加载入口。
