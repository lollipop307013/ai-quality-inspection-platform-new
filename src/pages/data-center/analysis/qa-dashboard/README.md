# 问答数据看板

- 访问路径：`/data-center/analysis/qa-dashboard`
- 菜单位置：数据中心 / 数据分析 / 问答数据看板

## 页面目标

集中查看业务接入知几 AI 问答服务后的基础问答规模、使用趋势、会话质量和高频问题，并按当前业务（game_id）提供「通用看板」与「业务看板」两种视图：

- 通用看板：跨业务统一的问答数据看板，覆盖周报视图、详细数据筛选及以下全部现有能力。
- 业务看板：按当前业务定制的看板。本期实现 PUBGM 项目组（`mock-game-pubgm`）与 FCM 项目组（`mock-game-fcm`）的定制看板；其他业务展示未配置空态。

## 功能范围

### 通用看板

- 顶部支持「通用看板 / 业务看板」切换。
- 周报视图默认展示上一自然周（周一00:00:00至周日23:59:59），可切换历史自然周。
- 详细数据筛选视图支持日期范围、近 7 天、近 30 天、自定义快捷项，以及按日、按周统计粒度。
- 数据概览展示用户 UV、用户消息总量、会话总量、人均消息数、人均会话数、会话平均消息数和连续追问会话占比；周报视图同时展示环比。
- 核心指标趋势展示用户消息总量、用户 UV 和会话总量；会话质量趋势展示连续追问会话占比。
- 高频问题表展示问题、次数、涉及用户和占比，并支持分页、每页条数切换和页码跳转。

### 业务看板

- 当顶部业务为 PUBGM 项目组（`mock-game-pubgm`）时，业务看板渲染 PUBGM 定制看板。
- 当顶部业务为 FCM 项目组（`mock-game-fcm`）时，业务看板渲染 FCM 定制看板。
- 其他业务展示未配置空态。

### 业务看板（PUBGM）

- 当顶部业务为 PUBGM 项目组（`mock-game-pubgm`）时，业务看板渲染 PUBGM 定制看板；其他业务展示未配置空态。
- 顶部「PUBGM 周报」周期切换，默认展示最新完整自然周（2026-07-20 ~ 2026-07-26），可切换历史自然周。
- **模块 1：数据概览**：提问对话量、提问用户量 UV、会话数、追问率（session）四个概览卡片；非全量灰度对比项以「--」展示。
- **模块 1：语种消息数与占比**：
  - 左侧环形图：每个扇区代表一个语种，扇区面积=该语种提问消息数占比；图中心展示提问消息总数与语种数。
  - 右上辅助汇总：TOP3 语种合计占比、TOP4 语种合计占比。
  - 右侧完整排行条形图：每行展示语种编码、语种名称、条形（按消息数比例）、消息数、占比；默认按消息数降序。
- **模块 2：用户反馈**：反馈对话占比、点赞率、点踩率、正反馈率、正负比，列表形式展示。
- 项目切换、看板类型切换与 PUBGM 周报周期切换均会清空 PUBGM 专属筛选并重新加载数据。

### 业务看板（FCM）

- 顶部「FCM 周报」周期切换，默认展示最新完整自然周（2026-07-20 ~ 2026-07-26），可切换历史自然周。
- **模块 1：整体概览**：用户 UV、用户消息数、会话总量、人均消息数、单次咨询平均消息数、连续追问会话占比六个概览卡片；其中人均消息数、单次咨询平均消息数高亮强调，连续追问会话占比以正向绿展示。
- **模块 2：使用规模与会话深度**：
  - 每日用户消息数（柱状图）：统计周期内每日用户消息量。
  - 高活跃用户下钻（列表，按消息量倒序，取 Top 12）：展示用户 OPEN_ID、消息数、占比与「查看对话」操作。
  - 「查看对话」打开弹窗，按时间顺序展示该用户当前周期的对话明细（Q + A）。
- **模块 3：提问内容及分类**：
  - 上半区：左侧一级分类分布环形图（5 个一级分类汇总），右侧 5 个一级分类下钻的二级分类环形图。
  - 类别明细列表：按一级类、二级类、描述、提问量、占比展示全部分类明细。
  - 高频提问 Top 30（样例）：按提问内容聚合，频次倒序展示问题、次数、类别与「查看问答」操作。
  - 「查看问答」打开弹窗，按时间顺序展示该提问的问答明细（Q + A）。
- **模块 4：用户属性与入口**：SVIP 用户占比数字卡，标注口径来自 `ext.is_svip` 字段。
- 项目切换、看板类型切换与 FCM 周报周期切换均会清空 FCM 专属筛选并重新加载数据。

## 交互与业务规则

- 看板类型切换位于页面最顶部、标题上方；「问答数据看板」标题始终展示。
- 周报/详细数据筛选切换仅在通用看板下出现；业务看板下展示 PUBGM 定制看板内容。
- 业务看板根据当前业务（game_id）决定内容；PUBGM 定制看板已实现，其他业务展示未配置空态。
- 通用看板的周报周期以自然周为单位。周选择器选中任意日期后，页面按该日期所在的周一至周日重新加载全部统计模块。
- 周选择器在通用看板与业务看板保持同一形态：输入框显示所选周的周序号，右侧注释文字给出该自然周的起止日期与时间口径。周序号与归属年由选择器按 ISO 规则给出，跨年周归属周四所在的年份。业务看板标题下方只标注当前项目名，不重复起止日期与周序号。
- 周选择器最晚只能选到上一个已完整结束的自然周。尚未结束的本周及以后的周整行禁用、不可点击，避免查出残缺周的统计结果。
- 通用看板的详细视图：日期与统计粒度作为待查询条件；点击「查询」统一更新指标、趋势与高频问题，点击「重置」恢复默认日期与按日统计。
- 通用看板详细视图的日期范围最晚只能选到昨天，当天及以后的日期禁用，因为当天数据尚未沉淀完整。
- 通用看板详细视图选择「按周」统计时，日期范围必须包含至少一个完整自然周（周一至周日）。不满足时点击「查询」不发起统计，提示「按周统计需包含至少一个完整自然周（周一至周日），请调整日期范围」；按周统计只产出完整自然周的数据点，残缺的周不会形成趋势数据。
- 通用看板周报视图显示指标环比，详细视图不显示环比；按周统计时趋势横轴按自然周呈现。
- 业务看板的 PUBGM 周报：默认展示最新完整自然周，可切换历史自然周；切换周后刷新所有模块数据。
- 业务看板在项目或看板类型切换时，清空 PUBGM 专属筛选并重新加载数据，避免数据串联。
- 加载、空数据和错误使用互斥页面场景表达。错误状态保留当前视图与筛选条件，重新加载成功后恢复完整数据。
- 全部统计 Mock 数据依赖顶部当前业务的 `game_id`；切换顶部业务后立即更新指标、趋势和高频问题，不改变当前预览场景；加载状态仅由页面预览场景控制。

## 数据口径

### 通用看板

- 用户 UV：周期内发送用户消息的去重用户数。
- 用户消息总量：周期内用户侧提问消息总条数。
- 会话总量：周期内去重会话数。
- 人均消息数：用户消息总量 / 用户 UV。
- 人均会话数：会话总量 / 用户 UV。
- 会话平均消息数：用户消息总量 / 会话总量。
- 连续追问会话占比：用户消息数不少于 2 的会话 / 会话总量。

### PUBGM 业务看板（数据表：海外 t_message_log；反馈表：t_user_feedback）

- 提问对话量：COUNT sender_type=1，统计周期内用户侧提问消息总条数。
- 提问用户量 UV：COUNT DISTINCT open_id WHERE sender_type=1，统计周期内发起提问的去重用户数。
- 会话数：COUNT DISTINCT e2e_session_id，统计周期内去重 e2e_session_id 数；跨天会话按最早消息日期归属。
- 追问率（session）：追问 session 数 / 总 session 数，反映用户多轮提问的活跃度。
- 语种消息数与占比：按 language_code 统计提问消息数，占比 = 各语种消息数 / 提问对话量。
- 反馈对话占比：有反馈对话量 / 总对话量。
- 点赞率：点赞对话量 / 总对话量。
- 点踩率：点踩对话量 / 总对话量。
- 正反馈率：点赞对话量 /（点赞 + 点踩对话量）。
- 正负比：点赞对话量 / 点踩对话量。

### FCM 业务看板（数据表：全量消息表 + 平台分类 Agent 结果）

- 用户 UV：COUNT(DISTINCT open_id) WHERE sender_type='user'。
- 用户消息数：COUNT(*) WHERE sender_type='user'。
- 会话总量：COUNT(DISTINCT e2e_session_id)。
- 人均消息数：用户消息数 / 用户 UV。
- 单次咨询平均消息数：用户消息数 / 会话总量。
- 连续追问会话占比：用户消息数 ≥ 2 的会话 / 全部会话。
- 每日用户消息数：COUNT(*) WHERE sender_type='user'，按日统计。
- 高活跃用户下钻：COUNT(*) WHERE sender_type='user' GROUP BY open_id ORDER BY COUNT(*) DESC LIMIT 12。
- 问题类别分布：基于分类 Agent 结果（L1/L2）按提问条数汇总占比。
- 高频提问 Top 30：按提问内容聚合，频次倒序，展示对应分类。
- SVIP 用户占比：COUNT(DISTINCT open_id) WHERE ext.is_svip=true / COUNT(DISTINCT open_id) WHERE sender_type='user'。

## 页面预览场景

以下场景为通用看板与业务看板共用的一套预览场景，通过看板类型切换查看不同看板下的对应状态：

- 周报正常有数据：上一自然周的指标环比、趋势和 Top 20 高频问题。
- 详细数据筛选：近 7 天详细视图，可实际修改日期、快捷项和统计粒度并查询、重置。
- 业务看板：切换到业务看板，展示按当前业务（game_id）定制的看板；PUBGM 项目组展示 PUBGM 定制看板，FCM 项目组展示 FCM 定制看板，其他业务展示空态。
- 看板加载中：保留页面结构，统一呈现统计加载反馈（通用看板与业务看板均适用）。
- 统计周期无数据：指标显示 `--`，趋势、高频问题、语种分布和用户反馈分别显示对应空态（通用看板与业务看板均适用）。
- 看板加载失败：保留视图和筛选条件，提供重新加载入口（通用看板与业务看板均适用）。
