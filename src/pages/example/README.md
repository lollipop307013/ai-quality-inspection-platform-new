# 应用管理

- 访问路径：`/#/example`
- 菜单位置：智能体 / 应用管理

## 页面目标

集中查看和管理当前空间内的智能体应用。

## 功能范围

- 按应用名称和状态筛选应用列表，并支持重置筛选条件。
- 新建应用，填写名称和负责人后加入列表。
- 编辑已有应用的名称和负责人。
- 直接切换应用的启用状态，并给出操作反馈。

## 交互与业务规则

- 应用名称和负责人均为必填项，应用名称不可与已有应用重复。
- 新建应用默认处于启用状态。
- 状态筛选为“全部状态”时显示全部应用。
- 重置操作恢复默认筛选条件。
- 应用列表 Mock 数据依赖顶部当前业务的 `game_id`。切换顶部业务后立即替换为对应业务的数据，不改变当前预览场景；加载状态仅由页面预览场景控制。

## 页面预览场景

- 正常有数据：默认筛选条件下展示可管理的应用列表。
- 列表加载中：首次进入页面时列表尚未返回数据，保留筛选区和列表结构，仅显示加载反馈，不展示业务数据或空态。
- 暂无应用：当前空间没有应用，空态可直接进入新建流程。
- 筛选无结果：保留已应用的筛选条件，并支持一键清除。
- 列表加载失败：保留筛选上下文，提供重新加载入口。
- 边界内容：使用长应用名称和负责人姓名验证表格截断与布局稳定性。
