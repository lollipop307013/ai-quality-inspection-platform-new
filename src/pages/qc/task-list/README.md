# 人工质检任务

- 页面名称：人工质检任务
- 访问路径：`/qc/task-list`
- 菜单位置：质检优化 / 人工质检任务

## 页面目标

展示当前业务下的人工质检任务卡片列表，支持按状态筛选、按任务名称搜索、分页浏览，并提供任务下载入口。

## 已确认的需求规则

- 任务卡片按当前顶栏业务选择器提供的 `game_id` 过滤，切换业务后任务列表随之刷新。
- 状态筛选（全部/进行中/待分配/待处理）与名称搜索为客户端实时过滤，互为 AND 关系。
- 卡片展示任务名称、状态标签、来源（场景/事件/渠道）、创建时间与进度（含进度条与完成数/总数）。
- 「下载」按钮弹出确认弹窗，展示任务摘要信息，确认后导出该任务信息为 CSV 文件（真实触发浏览器下载）。
- 「进入任务」当前给出迁移中的提示反馈；标注工作台页面本轮不在迁移范围内。
- 列表为空时区分「当前业务下尚未创建任务」与「筛选无结果」两种空态提示。

## 预览场景

| 场景 | 业务含义 |
|---|---|
| 正常有任务 | 当前业务下存在覆盖进行中、待分配、待处理三种状态的任务卡片 |
| 列表加载中 | 首次进入页面，任务列表尚未返回数据 |
| 暂无任务 | 当前业务下尚未创建任何人工质检任务 |
| 筛选无结果 | 任务数据存在，但当前筛选条件没有匹配结果 |
| 列表加载失败 | 任务列表请求失败，保留筛选条件并提供重试入口 |

## 尚未迁移
