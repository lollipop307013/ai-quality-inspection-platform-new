## 页面结构

顶部「‹ 返回列表 · 效果看板」面包屑 + 三个子 Tab（总览 / 策略详情 / 用户触达）+ 全局筛选（时间范围、渠道）。Tab 切换时保留时间与渠道筛选值。

### 全局筛选规则

- 时间范围：今天 / 昨天 / 近7天 / 近30天 / 自定义；除自定义外切换即刻生效
- 自定义：选择起止日期后点「查询」生效；校验起止必填、结束≥开始、起止≤当前日期、最长 365 天
- 渠道：全部渠道 / 企微 / 小程序 / 手Q，切换即刻生效
- 全部内容（指标卡、趋势图、Top5、策略列表、单策略面板、对比弹窗、用户触达）均跟随全局筛选联动；筛选变化后不在范围内的已选对比项自动清除

## 总览 Tab

- **指标卡（5 张）**：运行策略数 / 总推送量 / 总触达量（悬浮提示「需异步联动全量消息表进行检查，可能存在时延」）/ 推送失败率 / 超频拦截量
- **推送趋势（{时间范围} · 项目汇总）**：一张卡片内 3 张纵向堆叠小图（推送量 / 触达量 / 超频拦截量），每张 120px
  - 全部渠道时每图 3 条渠道曲线（小程序蓝 #3370ff、企微绿 #00b42a、手Q橙 #ff7d00），单渠道时仅 1 条
  - 时间跨度 > 31 天：3 张图均不渲染，显示「当前时间跨度较大，趋势图仅支持展示 31 天内的数据」
  - 无数据：显示「当前筛选范围内暂无数据」
- **拦截原因 Top 5**：行式进度条（超频限制 35% / 静默拦截 25% / 无可用渠道 20% / 服务已关闭 12% / 其他 8%），按数量降序

## 策略详情 Tab

- **筛选**：策略名称搜索 / 关怀类型（全部 + 失败关怀/回流关怀/新用户引导/活动提醒/打卡提醒）/ 状态（全部 + 生效中/已暂停/已完成/待启动/测试中/启动失败），与全局时间、渠道叠加生效
- **列表**：勾选 / 策略名称（关怀标签 chip + 生效时间）/ 渠道（点选对比）/ 状态 / 推送量 / 触达量 / 触达人数 / 推送失败率（红）/ 超频拦截量（橙）
- **排序**：生效中 → 已完成 → 已暂停/待启动/测试中/启动失败；同状态按名称拼音
- **范围外策略**：整行置灰 + 「不在筛选时间范围」标签，数据列 `--`，不可点选
- **选中与对比**（按钮在表格底部右侧）：
  - 对比单元 = 整策略（勾选框或点策略名）或 策略-渠道（点渠道 chip）；同策略下两者互斥
  - 最多 3 项，超出提示「最多只能选 3 项进行对比」；chip 满员后置灰不可点
  - 0 项：清除选择 / 对比按钮禁用；1 项：底部显示单策略详情面板，对比仍禁用；2~3 项：面板隐藏、对比可点
- **单策略详情面板**：标题「策略名 · 详细效果 · 聚合/渠道名」+ 状态；5 张指标卡（推送失败率红、超频拦截量橙）；拦截原因（1/3 宽）+ 渠道拆分（2/3 宽，仅整策略且 ≥2 渠道且顶部非单渠道时展示）；「‹ 返回策略列表」清空选中
- **对比弹窗**：标题「策略·渠道对比（N 项 · 时间范围）」；指标对比表（总推送量/总触达量/推送失败率/超频拦截量）；推送量/触达量/超频拦截量 3 张趋势对比图（共享图例）；渠道拆分对比表（整策略展开渠道行、单渠道仅 1 行）；仅「关闭」按钮，关闭不清空已选项

## 用户触达 Tab（三期）

- 输入单个 open_id，**输入实时刷新结果**；结果跟随全局时间范围与渠道筛选自动重查
- 结果表：触达时间 / 策略名称（含策略 ID）/ 关怀类型 / 渠道 / 触达状态（✓ 成功绿 / ✗ 失败红）/ 失败原因（一级原因中文，成功为 —）
- 边界：未输入显示引导；未找到显示「未找到用户 {open_id} 的触达记录」；用户存在但当前筛选无记录显示「用户 {open_id} 在当前时间范围及渠道：{渠道}下无触达记录」

## Mock 口径

- 10 条策略对齐设计稿（stg_001~stg_010，其中段位成长建议为草稿不进看板），状态覆盖生效中/已暂停/已完成/测试中/启动失败
- 指标随时间范围缩放：1 天 ×0.15、7 天 ×1、30 天 ×4.2、自定义按 days/7
- 派生公式：触达人数 = 触达量 × 0.92；失败率 = (推送-触达)/推送；超频拦截量 = (推送-触达) × 0.35
- 演示 open_id：10086 / 10087 / 10088 / 10089（记录集中在 2026-07-28 ~ 07-30，近 7 天查不到需切近 30 天）
- 趋势与对比图数据由确定性噪声生成，刷新不抖动

## 交接说明（开发需知）

- 数据来源：`care_delivery_tracking` 主动关怀埋点表；渠道字段 `delivered_channel`（成功与失败记录均需上报）
- 总触达量需异步联动全量消息表（`sender_type=push`，依赖需求 1010153191137442608 确认消息来源于主动关怀），前端需展示时延提示
- 关怀标签依赖子需求 1010153191137334964 在策略配置侧落库后回填
- 「返回列表」跳转主动关怀策略列表页（定位到当前策略所在页，三期实现）

## 预览场景

已声明 13 个互斥场景，通过 AppShell 原型工具逐项切换：

1. 正常有数据（近7天/全部渠道/总览）
2. 近 30 天多渠道
3. 时间跨度超过 31 天（趋势图不渲染）
4. 当前筛选范围无数据（自定义 2026-02-01~02-28）
5. 策略详情 - 选中 0 项
6. 策略详情 - 选中 1 项(整策略)
7. 策略详情 - 选中 1 项(单渠道)
8. 策略详情 - 选中 2~3 项（含对比弹窗）
9. 策略详情 - 关怀类型筛选
10. 用户触达 - 未查询
11. 用户触达 - 未找到用户
12. 用户触达 - 用户无记录（渠道过滤导致）
13. 用户触达 - 有记录
